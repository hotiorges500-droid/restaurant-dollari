# Restaurant DOLLARI

This is a responsive restaurant website created for Restaurant DOLLARI in Ratkoc, Rahovec, Kosovo. The goal is to present a professional local dining experience with a modern design, menu filters, gallery, and contact details.

## Technologies used

- HTML5
- CSS3
- Vanilla JavaScript

## Folder structure

```text
restaurant-dollari/
├── index.html
├── menu.html
├── about.html
├── gallery.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   └── icons/
└── README.md
```

## Important notes

This project is designed as a local restaurant showcase website. Some details such as exact phone numbers, social media pages, opening hours, and menu prices may not be publicly verified online, so this project uses realistic placeholder values and clearly indicates when verification is needed.

Key note:

- Menu prices are estimates and should be confirmed with the restaurant.
- Contact details are shown only as placeholders unless publicly confirmed.
- The project is designed for a professional presentation rather than as a fully connected business system.

## How to run the project

1. Open a terminal in the project folder.
2. Start a local web server:

```bash
python3 -m http.server 8000
```

3. Open the browser at:

```text
http://localhost:8000/
```

## Where to change content

- Main home content: index.html
- Food menu items and pricing: menu.html
- About text: about.html
- Gallery images: gallery.html
- Contact details and map: contact.html
- Design styling: css/style.css
- Interactions: js/script.js

## Image note

The project uses external public lifestyle and food photography for layout and design demonstration. If the real restaurant has its own official photos, replace the links in the HTML files with the restaurant-approved images.
